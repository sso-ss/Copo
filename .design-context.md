# CoPo design context

[DESIGN.md](DESIGN.md) is the official design standard for every CoPo UI
change. Read it first. It establishes warm neutral surfaces, ink text,
rounded corners and headings, calm spacing, and the existing companion artwork.
It supersedes conflicting historical notes; later explicit user direction wins.

This file is a short topic index. Keep design rules in `DESIGN.md` and detailed
implementation guidance in `docs/design/` rather than duplicating them here.

## Implementation reminders

- Declare values in `shell/src/ui/styles/theme.ts`, then regenerate with
  `scripts/generate-css-tokens.ts`. Keep Settings, Companion, and Dashboard
  synchronized in both themes.
- Use token names in components and documentation; preserve the original
  supplied artwork's palette separately from controls.
- Preserve localization, visible keyboard focus, contrast, and reduced motion.
- Keep sections typographic, avoid nested cards, and retain the live
  personalization preview.
- Do not treat old teal/crimson palettes or serif headings as current guidance.
